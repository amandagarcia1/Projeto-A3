Projeto desenvolvido para a disciplina **Programação de Soluções Computacionais**.
O sistema simula um DETRAN com cadastro de veículos, transferências e geração de placas no padrão Mercosul.

## Tecnologias
- Java (POO)
- MySQL
- JDBC

## Funcionalidades
- Cadastro e transferência de veículos com validação de CPF
- Geração e conversão automática de placas
- Relatórios e consultas por placa, CPF e histórico
- Persistência de dados com carga inicial via arquivos `.txt`

##  Organização
- `/model`, `/controller`, `/dao`, `/util`, `/view`
- `Main.java` para execução
- `script.sql` e arquivos `.txt` para banco e dados iniciais

##  Execução
1. Execute o script SQL no MySQL
2. Ajuste a conexão no código
3. Rode o `Main.java`
